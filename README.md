# プレゼン工房（Presentation Workshop）

プレゼンテーションの企画・構成・演出・制作・レビューを支える共通の制作基盤です。

## 制作ガイドライン

- [プレゼン工房 制作ガイドライン v1.2](guidelines/presentation_workshop_guidelines.md)
- 基本原則：**作り方を固定するのではなく、作り方を選択するための判断基準を固定する。**
- スライドの見栄えだけでなく、発表者の口頭説明、ページ送り、聴衆の反応まで含めた「発表全体」を設計します。

## 作品一覧

| 作品 | 内容 | 管理先 |
| --- | --- | --- |
| RPGで学ぶオブジェクト指向 | JavaScript RPGの改修を通じて設計判断を学ぶハンズオン教材 | [oop-rpg-workshop](https://github.com/Sarajevo001/oop-rpg-workshop) |

各作品は独立したGitHubリポジトリで管理します。ここには共通の規約、将来のテンプレート、作品へのリンクを置きます。作品のソースコードを移動・複製しません。

## 管理方針

- 共通規約の正本はこのリポジトリです。
- 個別作品の実装・公開設定・履歴は、それぞれのリポジトリで管理します。
- 規約の変更は既存作品へ自動適用されません。必要な場合に対象作品を確認して反映します。
- ChatGPTプロジェクトに添付した旧版ファイルは、このリポジトリの更新と自動同期されるものではありません。
